# Round 1 Learned Notes

## 1. 本轮哪些写法有效？

- 最有效方向是 candidate_08：高压开场后迅速转入轻巧错位，主角不表演情绪，而是确认、收证、找执行路径。
- candidate_04 证明“迟到资源”只需要一两个物品证据，不需要逐项解释所有礼包。
- candidate_06 的荒唐任务尾钩有效，因为荒唐不是笑完即止，而是被主角认真拆成可执行路径。
- candidate_05 的旧冲突错位有效：旧敌当年有重量，但现在不能重新膨胀成沉重大仇。

## 2. 本轮哪些写法失败？

- candidate_07 太低解释，虽然干净，但人物温度不足。
- candidate_02 的轻幽默有活气，但有稀释飞升失败压力的风险。
- candidate_05 后半偏抽象判断，像在证明主题。
- 多个候选的张前辈问答略多，容易变成配角捧哏或设定解释。

## 3. 下一轮必须继承什么？

- candidate_08 的轻巧、克制、自然节奏。
- candidate_04 的“少量物品证据”策略。
- candidate_06 的“荒唐任务认真执行”尾钩。
- 旧冲突必须同时保留当时重量和当前错位。

## 4. 下一轮必须避免什么？

- 避免逐项解释礼包。
- 避免大段解释系统逻辑。
- 避免配角连续提问来替作者说明。
- 避免把旧敌写成沉重大仇。
- 避免把低解释写成人物干瘪。

## 5. 哪些经验可能是通用 Skill 候选？

- 迟到资源只选一两个功能性证据。
- 旧冲突要保留“过去有重量、现在有错位”。
- 荒唐任务必须转化为下一步行动问题。
- 人物鲜活来自功能性判断，不来自小动作插件。

## 6. 哪些经验只是当前案例特有？

- 聚气丹、江一星、坟、牌位、族谱、旧演武场等执行物只能留在案例层。
- “新手流程赢死人”的具体桥段不能进入通用 Skill，只能抽象为“用规则承认的锚点测试边界”。
