# Round 3 Learned Notes

## 1. 本轮哪些写法有效？

- candidate_04 的收敛最好：单物品证据、旧冲突错位、低解释、荒唐任务尾钩都在。
- candidate_02 的“当时重 / 现在挡路”证明人物鲜活可以靠短促判断完成。
- candidate_03 的“新手任务就该用新手办法赢”是可用尾部温度，但旧冲突重量略弱。

## 2. 本轮哪些写法失败？

- 过短会让开场压力不足，像摘要。
- 尾钩若只写“查”而不写第一种执行办法，动力不够。
- 旧冲突若只作为任务目标，会回到人物干瘪。

## 3. 下一步必须继承什么？

- final output 应以 candidate_04 为底，吸收 candidate_02 的短促人物判断。
- 保留轻巧，不扩成 batch_01 recommended_output 那种解释更满的版本。
- 尾钩必须包含第一执行地点、失败后的备用路径和一点荒唐温度。

## 4. 仍未解决的问题

- 章内直接爽点仍偏少，更多是判断型爽点。
- 正文若扩长，仍有回到旧史堆砌的风险。
- 该方向适合第一章开局，但是否能支撑后续连续章节还需后续实验。
